# Semantic Study Guardian

An LLM-powered, privacy-preserving browser extension that helps students stay focused by semantically determining whether online content is relevant to their current study objective.

## Goal

Instead of blocking entire websites, this project analyzes webpage metadata using a local Large Language Model (LLM) and decides whether to allow or block the content based on the user's study goal.

## Tech Stack (Planned)

- Chrome Extension (Manifest V3)
- Python Backend (FastAPI)
- Local LLM
- GPU Inference
- JSON Communication
